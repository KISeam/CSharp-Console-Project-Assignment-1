# Assignment-1

A simple C# console application developed using .NET 10.0.  
This project demonstrates basic console output, program structure, and fundamental C# programming concepts.

---

## 📌 Project Overview

The application prints personal information to the console, including:

- Name
- Age
- Profession

This project is created as part of a C# Console Project Assignment.

---

## 🛠 Technologies Used

- C#
- .NET 10.0 SDK

## ▶️ How to Run

### Clone the Repository

```bash
git clone <your-repository-url>
```

### Navigate to Project Folder

```bash
cd Assignment-1
```

### Run the Application

```bash
dotnet run
```
